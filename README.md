# Página de Consulta

Um guia de estudos interativo para começar projetos web com HTML, CSS e a
metodologia BEM. Reúne o que aprendi nos meus estudos de front-end: estrutura de
pastas, semântica, regras de CSS, responsividade, Git e um checklist de entrega.

## Funcionalidades

- **Menu lateral** com todas as seções, que destaca a seção visível na tela. No
  celular e no tablet, vira um menu que abre pelo botão ☰.
- **Busca** em todo o conteúdo, sem diferenciar acentos (atalho: tecla `/`).
- **Checklist de entrega clicável**, com barra de progresso salva no navegador e
  um botão para começar um projeto novo.
- **Botão "Copiar"** em todos os blocos de código.
- **Abas** com modelos prontos de `index.html`, `index.css`, `fonts.css`,
  `page.css`, arquivo de bloco, README e arquivos de configuração.
- **Erros comuns** em formato de acordeão: o sintoma, a causa e a solução.
- **Tema claro e escuro**, que segue o sistema e lembra a sua escolha.
- **Botão de voltar ao topo** e link "Pular para o conteúdo" para quem navega
  pelo teclado.

## Tecnologias e técnicas utilizadas

- HTML5 semântico (`header`, `nav`, `main`, `section`, `aside`, `details`, `dl`)
- CSS3 com Flexbox, Grid e variáveis CSS (custom properties) para os temas
- Metodologia BEM com estrutura de arquivos BEM Flat
- Design responsivo com media queries nos pontos de interrupção 1024px e 544px
- Fonte Inter conectada localmente com `@font-face`
- JavaScript para a busca, o menu, as abas, o checklist e o tema
- `localStorage` para lembrar o tema e o progresso do checklist
- Acessibilidade: navegação por teclado, atributos ARIA nas abas e no menu, foco
  visível e respeito a `prefers-reduced-motion`
- Normalize.css (licença MIT) e fonte Inter (licença SIL Open Font License,
  em `vendor/fonts/LICENSE.txt`)
